in the paper. Git history (.git/) and build directories were stripped to
keep the archive small; the exact commit of each component is recorded
below so the build is still fully identifiable.

Upstream source: https://github.com/gotm-model/code

Build configuration used for this study:
    cmake -B build -DCMAKE_BUILD_TYPE=Release \
          -DGOTM_USE_STIM=ON -DGOTM_USE_CVMIX=ON -DGOTM_USE_FABM=OFF \
          -DSTIM_WINTON=ON -DSTIM_LEBEDEV=ON -DSTIM_MYLAKE=ON -DSTIM_BASAL_MELT=ON
    cmake --build build

The resulting `gotm` binary (at build/gotm) is what every gotm.yaml in
model_inputs/ was run with -- pass its path as the second argument to
run_gotm/run_gotm_case.sh.
